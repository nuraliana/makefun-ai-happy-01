A deterministic, stdlib-only Python program that draws "The robot's first picnic" — a small cream robot in a red scarf hands a sunflower to a laughing girl on a picnic blanket at golden hour, while a golden dog leaps beside them — and writes it to /output/entry.png for make.fun's "Make the AI judge happy" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Runs in under a second, no network, no dependencies beyond Python 3.12+. Two runs write byte-identical 800x800 PNGs (31 KB, under the 1 MiB / 1024x1024 limits).
